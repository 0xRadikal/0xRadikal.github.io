# 0xRadikal.github.io

Host-root files for `https://0xradikal.github.io/`.

GitHub Pages serves every project site of this account under this host
(`/Free-Telegram-Proxy/`, `/Free-v2ray-Configs/`, `/profile-card/`). Search
engines and AI crawlers only read `robots.txt` from the host root, so it has to
live in this repository, not in the project repositories.

- `robots.txt` — allows all crawlers and lists the project sitemaps.
- `.nojekyll` — files are served exactly as committed.

There is intentionally no `index.html` and no `404.html`, so nothing here
changes how the project sites behave.
